BREAKING NEWS STYLE PROMPT ENGINEERING - VISUAL COMPARISON
================================================================================

Problem: Users felt analyses sounded "dated" because LLM focused on historical
         trends rather than current data.

Solution: Restructured prompts to force 80% focus on last 3-6 months and 
          immediate lead with latest figure.

================================================================================
PROMPT STRUCTURE ENHANCEMENT
================================================================================

User Prompt Evolution:

BEFORE (Unstructured):
  "Analyze the following economic data for Real GDP.
   Recent Data: [table]
   Provide professional analysis..."

AFTER (Structured with Priority):
  "LATEST DATA (2024-06-30): Real GDP: 107.00
   
   RECENT MOMENTUM (3-month trend): Real GDP is up 2.9%
   
   FULL DATA CONTEXT (Last 24 Periods):
   [table]
   
   Analyze the immediate direction..."

Key Improvements:
  ✅ Three clear sections with visual hierarchy
  ✅ LATEST DATA section immediately draws AI attention
  ✅ RECENT MOMENTUM provides directional context
  ✅ FULL DATA CONTEXT demoted to supporting role
